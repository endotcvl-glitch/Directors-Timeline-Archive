Principles

このサイトは、映画監督の作品年表と時代背景を静かに眺めるためのアーカイブです。装飾ではなく、情報の整理そのものをデザインの中心に置きます。

Minimal 余白、罫線、文字の強弱で構成する。
Typographic 画像装飾よりも、文字の階層で情報を読ませる。
Archive レビューサイトではなく、年表アーカイブとして振る舞う。

Color

`style.css` のCSS変数を基準にしたカラーパレットです。色数を増やさず、背景、文字、補助情報、罫線、アクセントで整理します。

Layout Width

PC表示では主要な一覧・情報ページの外側幅を1100pxに揃えます。長文本文は読みやすさを優先して760px程度に絞ります。

Outer Content / 1100px

years.html、today.html、notes/index.html、notes/*.html の外側コンテナ。

Reading Width / 760px

Editor's Notes の本文など、長文を読むエリア。

Mobile Reference / 1rem Padding

スマホでは左右余白を1rem程度にして、無理にPC幅を維持しない。
