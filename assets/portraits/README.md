# Director Portraits

このフォルダには、サイトで使用する監督ポートレートの完成版のみを保存します。

## 保存ルール

- 画像を生成しただけでは、このフォルダへ格納しない。
- ユーザーが明示的に「保存して」と指示した画像だけを、このフォルダへ格納する。採用や保存の指示が出るまではプレビューとして扱う。
- 新規生成・再生成・バリエーション生成のたびに、前回や既存ポートレートとは異なるポーズにする。固定の構図と頭部スケールは維持しながら、視線、顔の角度、肩の向き、顎の高さなどを変える。
- ファイル名は監督の英語フルネームを小文字のケバブケースにする（例: `steven-spielberg.png`）。
- ファイル形式は PNG とする。
- 画像は正方形とする。
- サイトでの使用サイズは 180 × 180 px とする。元データは高解像度でもよい。
- ポートレートは [`directors-portrait-style-guide.md`](../../docs/directors-portrait-style-guide.md) に準拠する。
- 今後の油彩タッチと仕上げは [`ari-aster.png`](./ari-aster.png) を主要な基準画像とする。顔立ちやポーズはコピーせず、筆致、面構成、輪郭処理、衣服の省略度を参照する。
- 筆数を減らし、額、頬、鼻、顎、首を少数の大きな明暗面と大胆で方向性のある筆使いで構成する。
- 髪は人物本来の生え際、輪郭、長さ、ボリュームを保ち、5〜10程度の太い方向性のある塊を基本とする。その内部に中程度の毛束を少数だけ加えて自然な流れを示してよいが、一本ずつの毛や細かな反復線にはしない。
- 髭は細かな反復描写や点描を避け、連結した大きな面として表現する。
- 衣服は細かな皺や質感を描き込まず、少数の暗く大きな形へ簡略化する。
- 背景色はすべて正確な `#1E1E1E`（RGB `30, 30, 30`）に固定する。グラデーション、粒子、筆致、テクスチャ、色むら、ビネット、光彩は加えない。
